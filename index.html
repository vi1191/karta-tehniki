👋 Добро пожаловать!

Карта техники Жилищника — Тропарёво-Никулино

🗺

Что это за приложение?

Интерактивная карта маршрутов уборочной и дорожной техники. Смотреть — без регистрации, редактировать — в режиме «✏️ Редактировать».

📋

Список техники

Слева — все машины, сгруппированы по подтипам.

  • Клик по карточке — открыть маршрут
  • Наведение — подсветка маршрута на карте
  • Галочка — отметить для показа
🎯

Категории и участки

Сверху — ОДХ / Дворы / Вся техника. Кнопки 1–6 фильтруют по участкам (панель открывается отдельной кнопкой).

🚜

Маршруты

У машины может быть до 5 маршрутов. Кнопки печати: 🖨 Печать маршрута (таблица) и 🖨 Печать карты (карта в новом окне со всеми инструментами).

✏️

Редактор

Включается кнопкой «✏️ Редактировать». Выберите объект на карте — точки сразу можно перетаскивать. Кнопка «✏️ Точки» добавляет новые точки кликом по карте, правый клик по точке — контекстное меню (удалить, вставить, очистить линию). «➕ Линия» — новая дополнительная линия, «🔗 Соединить» — склеить две линии. Esc — выход из любого режима.
